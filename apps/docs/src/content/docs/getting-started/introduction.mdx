Ecopages is an **HTML-first** framework for multi-page apps. You write TypeScript that returns HTML. A page is a file. The default output is static. Islands and a server are there when you need them.

It runs on Node.js and Bun.

The default Ecopages JSX stack does not require a virtual DOM or a new reactivity system. Import CSS next to the page. Import a component and use it.

## What makes it different?

Most frameworks ask you to adopt a new way of thinking first. Ecopages starts from the web you already know: files, HTML, CSS, and TypeScript.

- **A page is a file.** `src/pages/about.tsx` is `/about`.
- **Static by default.** Build HTML once and host `dist` anywhere. Add APIs or request-time pages only when you need them.
- **Choose a renderer.** [Ecopages JSX](/docs/integrations/ecopages-jsx) is the default for `.tsx`. [React](/docs/integrations/react), [Lit](/docs/integrations/lit), [MDX](/docs/integrations/mdx), and [KitaJS](/docs/integrations/kitajs) are optional.
- **Typed server when you want it.** `app.get()`, `defineApiHandler`, middleware. Unused if you only ship static pages.

The default bundler is [Rolldown](https://rolldown.rs). Add the [PostCSS processor](/docs/ecosystem/postcss-processor) when you need Tailwind or need to import CSS as a JavaScript string.

## Quick example

### 1. Create a component

```tsx
// src/components/greeting.tsx
import { eco } from '@ecopages/core';
import type { JsxRenderable } from '@ecopages/jsx';
import './greeting.css';

export const Greeting = eco.component<{ name: string }, JsxRenderable>({
	render: ({ name }) => <div class="greeting">Hello, {name}!</div>,
});
```

### 2. Create a page

Import local components and CSS directly:

```tsx
// src/pages/index.tsx
import { eco } from '@ecopages/core';
import { Greeting } from '@/components/greeting';
import './index.css';

export default eco.page({
	metadata: () => ({
		title: 'Welcome to Ecopages',
	}),
	render: () => (
		<main>
			<h1>Welcome to Ecopages</h1>
			<Greeting name="Developer" />
		</main>
	),
});
```

### 3. Add a typed API handler

Inline for a one-off endpoint:

```typescript
// app.ts
import { createApp } from '@ecopages/core/create-app';

const app = await createApp();

app.get('/api/hello', async (ctx) => {
	return ctx.response.json({ message: 'Hello world!' });
});

await app.start();
```

For larger apps, `defineApiHandler` infers body, query, and path types from the schema:

```typescript
// handlers/greet.ts
import { defineApiHandler } from '@ecopages/core';
import { z } from 'zod';

export const greetHandler = defineApiHandler({
	path: '/api/greet',
	method: 'POST',
	schema: {
		body: z.object({ name: z.string() }),
	},
	handler: async (ctx) => {
		const { name } = ctx.body;
		return ctx.response.json({ message: `Hello, ${name}!` });
	},
});
```

```typescript
// app.ts
import { createApp } from '@ecopages/core/create-app';
import { greetHandler } from './handlers/greet';

const app = await createApp();
app.add(greetHandler);
await app.start();
```
