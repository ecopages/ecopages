# Introduction

Welcome to the docs starter. Content files live under `src/content/docs` and are rendered through one catch-all route.

## How it works

1. Add MDX under `src/content/docs/<section>/<slug>.mdx`.
2. Register the page in `src/docs-kit/manifest/docs-manifest.config.ts`.
3. The catch-all page compiles MDX at request/build time and wraps it in the docs layout.
