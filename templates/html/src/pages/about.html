About

This page is a plain HTML file, src/pages/about.html. Its <title> and description replace the ones in the shell, and its markup renders where the shell writes <!-- eco:children -->.

What you can write

  • A body fragment: markup with no <head>.
  • A <head> followed by body markup, like this file.
  • A complete document with a doctype, <html>, and <body>.

Local stylesheets and scripts resolve against the file that references them. Put images and fonts in src/public and reference them with root-relative URLs.
