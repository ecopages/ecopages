# Documentation

This page is rendered entirely from **MDX**. It uses the same `BaseLayout` as the rest of the app, so the header, theme toggle, and navigation behave consistently.

## Features

- **Component integration**: Use JSX components directly inside Markdown.
- **Layout support**: Declare a layout in the MDX frontmatter or via `config`.
- **Static generation**: Pages are rendered at build time and hydrated only where needed.

```typescript
import { BaseLayout } from '../layouts/base-layout';

export const config = {
    layout: BaseLayout,
};
```
